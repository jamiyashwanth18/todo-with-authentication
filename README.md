# TODO with authentication

Build a simple To-Do web app with login.
 
- Users sign up with name, email and password, and sign in with email and password.
- A wrong email or password shows "Email or password is incorrect".
- Passwords are stored hashed.
- Users can sign out. A signed-out user who opens a private page goes to the sign-in page.
- A signed-in user can add, edit, complete and delete tasks.
- Each user sees only their own tasks.
- Pages: Sign up, Sign in, My tasks.
- Out of scope: password reset, social login, roles.

Generated by the Quorq AI SDLC platform. Two applications, one repository:

- **`frontend/`** -- the approved app design as a Vite + React SPA. Every screen
  was reviewed and approved, and runs on seeded sample data.
- **`backend/`** -- a FastAPI service. No architecture had been approved
  when this repository was created, so it starts with its health check and
  nothing else.

## Running it

```bash
cd frontend
npm install
npm run dev
npm test          # unit tests (Vitest)
npm run lint       # ESLint
npm run format     # Prettier
```

```bash
cd backend
pip install -r requirements.txt
uvicorn app.main:app --reload
pytest
ruff check .
ruff format .
```
