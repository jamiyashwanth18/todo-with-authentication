# TODO with authentication — SDLC Documentation

> Maintained by QuorQ AI SDLC. Text between `sdlc:auto` markers is regenerated; anything outside them is yours and is kept.

<!-- sdlc:auto:start overview -->
Build a simple To-Do web app with login.
 
- Users sign up with name, email and password, and sign in with email and password.
- A wrong email or password shows "Email or password is incorrect".
- Passwords are stored hashed.
- Users can sign out. A signed-out user who opens a private page goes to the sign-in page.
- A signed-in user can add, edit, complete and delete tasks.
- Each user sees only their own tasks.
- Pages: Sign up, Sign in, My tasks.
- Out of scope: password reset, social login, roles.

**Documentation version:** v1
